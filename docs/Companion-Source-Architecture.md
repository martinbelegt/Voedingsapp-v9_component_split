# Companion Source Architecture

## Doel

Dit document beschrijft hoe de `src`-map van Companion uiteindelijk logisch wordt opgebouwd.

De bestaande code wordt niet in één keer verplaatst. We werken stap voor stap, per onderdeel, met kleine commits.

---

# Gewenste hoofdstructuur

```txt
src/

├── app/
├── core/
├── features/
├── ui/
├── hooks/
├── services/
├── data/
├── assets/
├── utils/
└── styles/
```
