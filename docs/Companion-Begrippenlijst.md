# Companion-begrippenlijst

| Technische term | Betekenis | Praktisch gebruik |
| --- | --- | --- |
| Foundation | Fundament | Gedeelde basiscomponenten en stijlen |
| Domain component | Domeincomponent | Component voor een specifiek Companion-domein |
| Feature | Functionaliteit | Concrete functie voor de gebruiker |
| Card | Kaart | Visuele container voor gegroepeerde inhoud |
| Badge | Statuslabel | Kleine indicator voor status of categorie |
| Chip | Keuzechip | Compacte keuze of filter |
| Toolbar | Werkbalk | Rij met acties of hulpmiddelen |
| Playground | Proeftuin | Omgeving voor functioneel uitproberen |
| Design Lab | Ontwerplab | Omgeving voor visuele ontwerpcontrole |
