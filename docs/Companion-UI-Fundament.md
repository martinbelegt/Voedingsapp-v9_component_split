# Companion UI Fundament

## Doel

Alle herbruikbare visuele en interactiepatronen van Companion centraal vastleggen, zodat Dashboard, Tijdlijn, Voedingsbibliotheek en toekomstige modules dezelfde basis gebruiken.

## Waarom

Op dit moment staan veel stijlen en interacties verspreid over losse componenten. Daardoor kunnen kleine wijzigingen onverwacht effect hebben op andere schermen.

Het UI Fundament moet zorgen voor:

- consistente knoppen
- consistente invoervelden
- consistente kaarten
- consistente datum/tijd-selectie
- consistente modals en mobile sheets
- minder dubbele code
- minder visuele verschillen tussen iPhone en desktop

## Eerste bouwstenen

### uiTokens

Centrale maten, kleuren en dichtheden.

### Buttons

Standaardknoppen, compacte knoppen, actieknoppen en gevaar-knoppen.

### Inputs

Input, select, textarea en mobiele anti-zoom regels.

### Cards

Standaardkaart, compacte kaart, sectiekaart.

### DateTimePicker

Eén centrale manier om datum en tijd te kiezen.

### MobileSheet / ModalShell

Eén centrale basis voor modals op desktop en full-screen sheets op mobiel.

### SectionToggle

Eén centrale manier voor inklapbare blokken.

### ActionBar

Eén centrale manier voor Verwijderen / Opslaan / Annuleren.

### TimelineItemShell

Eén centrale basis voor tijdlijnitems.
